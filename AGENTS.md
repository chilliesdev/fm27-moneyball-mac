# Imported metrics

- Before adding or changing an imported metric, verify support in the installed reader for the selected game version.
- Keep unavailable data distinct from a real zero. Do not replace unavailable data with zero or include it in percentiles or role scores.

## Metric QA

- Test an unsupported or missing value, a real zero, and a known non-zero value.
- Verify unavailable data is shown as unavailable and has no percentile or role-score contribution.
- Verify a real zero remains zero and a known non-zero value keeps its expected value and score.
